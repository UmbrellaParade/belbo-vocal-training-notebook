歌の気づき、Codexの考察、検証結果を分けて蓄積・振り返る個人用研究ノートです。

== Description ==

WordPress管理画面の「歌の研究ノート」から利用します。

* 自分の気づきと仮説を分けて保存
* Codexの意見・発展仮説を別欄に保存
* 次に試すこと、試した結果を記録
* 状態・テーマ・キーワードで振り返り
* 全件をJSONバックアップとして書き出し
* GitHub Releases経由の更新通知

ノートは非公開のカスタム投稿としてWordPress内に保存され、管理画面にログインできるユーザーだけが操作できます。
