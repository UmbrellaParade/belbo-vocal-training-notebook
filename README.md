# べるぼ ボーカル研究ノート

歌の気づき、Codexの考察、検証結果を分けて蓄積し、自分の声の取扱説明書を育てるWordPressプラグインです。

## 主な機能

- 気づき・自分の仮説・Codexの意見を分離して保存
- 次に試すことと、試した結果を記録
- 「未検証／検証中／有力／定着／見直し」の状態管理
- テーマ、状態、キーワードによる検索・絞り込み
- JSONバックアップの書き出し
- GitHub ReleasesからWordPressの更新通知を取得

## インストール

1. Releasesから `belbo-vocal-training-notebook.zip` をダウンロードします。
2. WordPress管理画面の「プラグイン > 新規追加 > プラグインのアップロード」からZIPをインストールします。
3. 有効化すると、管理メニューに「歌の研究ノート」が表示されます。

## リリース手順

ZIP内の先頭ディレクトリは `belbo-vocal-training-notebook/` とします。GitHub ReleaseのタグとプラグインヘッダーのVersionを一致させ、リリース資産名を `belbo-vocal-training-notebook.zip` にします。
